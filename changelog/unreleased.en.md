No changes to the app; what's new is the feature set of the web version.

Web version:
- Almost everything the app does now works in the browser too: editing subjects (color, short names for all types and per type with a preview, rhythm, moving courses), notes and own changes, "Cancelled for me", "Choose dates" and own courses, also on weekends
- Hiding (a date, a subject, only one type or one group) with "Undo" and the "Hidden" list to bring things back
- Friends from an .ics file, a friend's courses "Add to my plan", courses from another .ics, renaming friends, marking favorites and sorting them by dragging, "Free together" in the day view
- All color schemes of the app (System, Soft, AMOLED, Custom with the color editor), "Fit to screen in landscape", the version overview, licenses and "Share the web app" by QR code
- Messages as in the app: swipe them away, tap long ones to expand
- Keyboard shortcuts (? shows them)
- Backups hold all of it in the same format as the app and move between the app and the browser in both directions
